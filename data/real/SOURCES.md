Downloaded 2026-09-16 from the URLs below (`download_real_data.sh` fetches the same files; the zip archives are the providers' originals, the CSVs their contents; `CHECKSUMS.sha256` lists the snapshot). The files are **not redistributed with the code**: ECB data may be reproduced with the source acknowledged, and the Ken French library is provided for research use with acknowledgement of the source, so the released repository ships the download script and this file, and each user fetches the data from the providers. Both providers extend their files over time; `code/real_data.py` cuts a later download at the snapshot's last dates (`--end-fx 2026-09-15`, `--end-eq 2026-07-31`) and `--expect results/real_windows_fingerprint.json` confirms that the rebuilt windows are the paper's.

## What is used (`code/real_data.py`)

- FX: twenty floating currencies against the euro (USD, JPY, GBP, CHF, AUD, CAD, SEK, NOK, NZD, MXN, ZAR, BRL, KRW, PLN, HUF, CZK, SGD, INR, ILS, IDR); the rate itself is the level series. Pegged or managed currencies (DKK, HKD, CNY, …) are not used. Observations before 2015-01-01 are ignored.
- Equities: the market return (Mkt-RF + RF) and every one of the 49 value-weighted industry portfolios with no missing value since 2015-01-01; levels rebuilt as 100·∏(1+r). Only the first (value-weighted) block of the industry file is read.
- Windows: context 512 + horizon 128 trading days, non-overlapping futures per series (stride 128), counted backwards from the last observation. The paper's anchor (`--k 0 --n-sur 4`) keeps every such window since 2015: 1280 windows (380 FX, 900 equity), futures ending between 2017-09-12 and 2026-09-15 (FX) / 2017-11-30 and 2026-07-31 (equities), of which 280 end after 2025-01-01. The first, smaller anchor (`--k 8 --n-sur 1`, files `*_v1`) kept the latest 8 windows per series: 560 windows (160 FX, 400 equity).
- Surrogates: every window's 639 simple returns are multiplied by i.i.d. ±1 signs (`numpy.random.default_rng(5000 + window_index + 100000 * draw)`, draws 0..3) and the level is rebuilt multiplicatively, which makes the level an exact martingale while keeping the real |return| path. Nothing else is altered; no window, asset or day is excluded beyond the rules above.
- Per-window scale: `sigma_*` = standard deviation of the level increments over the context, `rsigma_*` = standard deviation of the simple returns over the context (raw and surrogate separately); the paper reports every real-data metric in return units. Medians over the 1280 windows: σ/level FX 0.45 %, equities 1.20 % per day; return σ FX 0.46 %, equities 1.41 %.

## Pretraining overlap

Public daily FX and equity series may appear in the models' pretraining corpora (Chronos and Moirai list an exchange-rate dataset ending in 2016; Time-300B includes a finance domain; FinCast is finance-native). The surrogate windows are new sequences by construction. For the raw windows the split "futures ending after 2025-01-01" postdates the published training cut-offs of Chronos, Moirai, TimesFM-2.0 and Time-MoE, and is reported separately.
